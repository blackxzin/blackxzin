## Sobre mim

Sou Lucas Gabriel, estudante de Análise e Desenvolvimento de Sistemas e desenvolvedor Full Stack. Construo projetos que combinam interfaces, APIs, bancos de dados e automação. Tenho especial interesse em backend, Linux e segurança aplicada ao desenvolvimento.

Gosto de entender o problema antes de escolher a tecnologia, documentar o que construo e evoluir cada projeto com testes e feedback.
