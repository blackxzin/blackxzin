## Como trabalho

1. Entendo o problema e defino o resultado esperado.
2. Escolho uma arquitetura simples, segura e adequada ao contexto.
3. Desenvolvo em pequenos incrementos, com código legível e testes.
4. Documento decisões, limites e como executar o projeto.
5. Valido o comportamento e preparo a entrega para operação.
